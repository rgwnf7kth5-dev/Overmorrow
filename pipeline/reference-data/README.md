# Reference data

Base rates computed from real data, for step 4.1 of [METHODOLOGY.md](../../METHODOLOGY.md) (outside view). Each JSON file is generated by a script in `scripts/refdata/` (Node 20, no npm dependencies; `unzip` and, as a fallback, `curl` CLIs). Downloads are cached in `work/refdata-cache/` (gitignored).

| File | Script | Source |
|---|---|---|
| `cz-chamber.json` | `node scripts/refdata/psp.mjs [--refresh]` | psp.cz open data (votes, deputies/clubs, bills, agendas) |
| `poll-error.json` | `node scripts/refdata/poll-error.mjs [--refresh]` | Poll figures transcribed in the script with URLs; Czech results downloaded from volby.cz XML |
| `central-banks.json` | `node scripts/refdata/central-banks.mjs [--refresh]` | cnb.cz repo history file, ecb.europa.eu key rates, federalreserve.gov open market table |
| — | `scripts/refdata/models.mjs` | probability helpers (module + CLI) |

Every number has a `definition` in the JSON. Re-run the scripts before relying on recent counts.

## Models (`scripts/refdata/models.mjs`)

```js
import { pLeadAbove, pWinFromPolls, pAtLeastK, pReleaseAbove } from '../../scripts/refdata/models.mjs';
```

| Function | Model | CLI |
|---|---|---|
| `pWinFromPolls(leadMean, errorSd)` | P(true lead > 0), lead ~ Normal(poll lead, errorSd) | `node scripts/refdata/models.mjs lead 2.0 3.5` |
| `pLeadAbove(leadMean, leadSd, threshold)` | P(true lead > threshold) | `node scripts/refdata/models.mjs leadabove 2.0 3.5 1` |
| `pAtLeastK(n, pEach, k)` | Binomial P(X ≥ k) | `node scripts/refdata/models.mjs atleast 108 0.98 105` |
| `pReleaseAbove(consensus, threshold, surpriseSd)` | P(release > threshold), release ~ Normal(consensus, surpriseSd) | `node scripts/refdata/models.mjs release 2.4 2.5 0.15` |

### Which sd to use for poll leads (from `poll-error.json`)

Lead error = poll lead − actual lead of the top two finishers (pp).

| Class | Lead errors | RMS lead error (use as `errorSd`) |
|---|---|---|
| Czech parliamentary 2017, 2021, 2025 (final polls ~1 week out) | −2.2, −5.9, +0.4 | **3.6** |
| Brazil runoffs 2014, 2018, 2022, Datafolha final poll, valid votes | +0.7, −0.3, +2.2 | **1.3** |
| Pooled, 6 elections | mean −0.8, sd 2.85 | **2.7** |

Per-party error (poll − result): Czech sd 2.9 pp (23 party-elections); mean absolute error per Czech election 2.0–2.5 pp. Small samples: with three elections per class, treat these as lower bounds and prefer the larger value when in doubt. For a single poll instead of an average, add sampling error: `sqrt(errorSd² + (2·sqrt(p(1−p)/n)·100)²)` for the lead.

Example: final Czech polls show party A ahead by 3 points → `pWinFromPolls(3, 3.6)` ≈ 0.80.

### Coalition votes in the Czech Chamber (from `cz-chamber.json`)

Use the empirical table `coalition_discipline[].<class>.p_yes_at_least_S_minus_k` rather than the binomial: absences are correlated. Classes: `contested_votes` (all government-vs-opposition votes), `contested_full_house_votes` (≥180 deputies logged in, a proxy for flagship votes), `contested_absolute_majority_votes` (quorum 101), `contested_final_passage_votes`.

P(coalition yes votes ≥ S − k):

| Coalition | Class | n | k=0 | k=1 | k=2 | k=3 | k=4 | k=5 |
|---|---|---|---|---|---|---|---|---|
| Fiala (5 clubs, S=108) | contested | 572 | 0.000 | 0.002 | 0.004 | 0.004 | 0.011 | 0.018 |
| Fiala (5 clubs, S=108) | full house | 37 | 0.000 | 0.027 | 0.054 | 0.054 | 0.135 | 0.216 |
| Fiala (4 clubs, S=104) | full house | 77 | 0.013 | 0.026 | 0.078 | 0.130 | 0.234 | 0.273 |
| Babiš (ANO+SPD+Motoristé, S=108) | contested | 397 | 0.005 | 0.025 | 0.033 | 0.033 | 0.058 | 0.063 |
| Babiš (ANO+SPD+Motoristé, S=108) | full house | 25 | 0.080 | 0.400 | 0.520 | 0.520 | 0.640 | 0.680 |

So "at least 105 of 108 coalition deputies vote yes" (k=3) has a base rate of about 3% on an ordinary contested vote, and about 50% on a flagship full-house vote for the current coalition (n=25, wide uncertainty). The median shortfall on ordinary contested votes is about 19–24 deputies; coalition attendance (logged in) averages 79–84%.

If you need the binomial anyway: `pAtLeastK(108, pEach, 105)` with `pEach` = the class's mean `yes_share`.

### Bills

- Bills on which a third-reading vote was held and that passed (hist.unl): 9th term 256/258 (99.2%), 10th term so far 29/30. Government bills referred to committee or approved in first reading: 290/290 decisive outcomes in the 9th term, 47/47 in the 10th (withdrawals excluded). Failed final votes on bills later passed at a repeat attempt are not counted as failures at bill level; vote-level failure of a final vote is not identifiable from the open data alone.
- Agenda items: an item on a meeting's approved agenda is completed at that meeting only ~21–24% of the time (items roll over between parallel meetings); items with a fixed date/slot note were completed 67% of the time in the 9th term. This measures completion within the meeting, not on a specific day.

### Data releases and central banks

`pReleaseAbove` needs a surprise sd for the specific indicator (for example, the historical sd of actual − consensus for Czech CPI); this repository does not yet contain such a series, so take it from the source used for the consensus and record it in the rationale.

`central-banks.json` lists every rate change since 2022 for ČNB, ECB and Fed from the official tables (holds are not in those tables). The comparison with the prior Reuters-poll consensus has **not** been filled in: no row was verified, so `share_matching` is `null`. Add rows to the `CONSENSUS` map in `scripts/refdata/central-banks.mjs` only with a cited source.
